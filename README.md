# weather-forecast-app
responsive Weather Forecast Web Application that provides real-time weather updates and 5-day forecasts using the OpenWeatherMap API. The application displays temperature, humidity, wind speed, weather conditions, and visualizes forecast data through interactive charts.

## Features
- Search weather by city name
- Automatic location detection using Geolocation API
- Current weather information
- Temperature, humidity, and wind speed display
- 5-day weather forecast
- Interactive weather charts using Chart.js
- Responsive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- OpenWeatherMap API
- Chart.js

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Replace the API key in app.js with your OpenWeatherMap API key.
4. Open index.html in any web browser.

## API Used

OpenWeatherMap API

Endpoints:
- Current Weather API
- 5-Day Forecast API
